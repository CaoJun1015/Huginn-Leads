# 外部数据源

Huginn Leads 可以从本机 SQLite 数据库只读导入业务记录，将结果保存在自己的数据库中，再发布为线索任务。外部系统不会被修改。

## 设计边界

- 数据源只固定保存连接、外部键和导入状态。
- 业务字段由“业务模式”定义，可以是库存、房源、服务或其他记录。
- 查询和字段映射可配置；Diaohuo 只是一个可选示例。
- 导入和发布分开：先预览，再写入 Huginn 快照，最后发布任务。

## 使用流程

1. 在“业务模式”中选择或创建字段模板。
2. 在“外部数据”中添加 SQLite 数据源。
3. 填写数据库绝对路径、只读查询、外部键列和字段映射。
4. 选择将来任务要监控的 QQ 群或联系人。
5. 点击“预览变化”，核对新增、更新和失效数量。
6. 确认导入后，点击“发布任务”。

## 查询契约

- 只允许一条 `SELECT` 或 `WITH` 查询。
- 单次最多读取 5000 条。
- 查询结果必须包含配置的唯一标识列，且每行不得重复。
- 需要聚合、去重或过滤的数据，应在只读查询中完成。
- 字段映射格式为 `{"Huginn 字段":"查询结果列"}`。
- 默认值用于外部数据没有的固定业务值，例如任务方向。

## Diaohuo 示例

选择“Diaohuo 电脑库存示例”后，只需填写 `diaohuo.db` 的实际路径和 QQ 监控来源。预设会按完整规格合并有效库存，并把记录发布为寻找采购需求的任务。路径、查询和字段映射都可修改，核心导入器不依赖 Diaohuo 代码。

## 当前限制

- 只支持本机 SQLite，只支持手工触发导入。
- 已发布任务不会被后续导入自动覆盖，避免丢失人工修改。
- 外部记录后续消失时，Huginn 会将本地快照标为失效，但不会自动删除或停用已发布任务。
- 暂不反向写入外部系统，不做自动报价、出库或库存扣减。
