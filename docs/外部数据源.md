# 外部数据源

Huginn Leads 可以从本机 SQLite 数据库只读导入业务记录，将结果保存在自己的数据库中，再发布为线索任务。外部系统不会被修改。

## 设计边界

- 数据源只固定保存连接、外部键和导入状态。
- 业务字段由“业务模式”定义，可以是库存、房源、服务或其他记录。
- 查询和字段映射可配置；Diaohuo 只是一个可选示例。
- 导入和发布分开：先预览，再写入 Huginn 快照，最后发布任务。

## 使用流程

1. 在“业务模式”中选择或创建字段模板。
2. 在“外部数据”中添加 SQLite 数据源。
3. 填写数据库绝对路径、只读查询、外部键列和字段映射。
4. 配置强别名字段；如有简称，配置“弱别名查询列”。
5. 选择将来任务要监控的 QQ 群或联系人。
6. 点击“预览变化”，核对新增、更新和失效数量。
7. 确认导入后，点击“发布任务”。

## 查询契约

- 只允许一条 `SELECT` 或 `WITH` 查询。
- 单次最多读取 5000 条。
- 查询结果必须包含配置的唯一标识列，且每行不得重复。
- 需要聚合、去重或过滤的数据，应在只读查询中完成。
- 字段映射格式为 `{"Huginn 字段":"查询结果列"}`。
- 默认值用于外部数据没有的固定业务值，例如任务方向。
- `alias_fields` 来自已映射的 Huginn 字段，生成强别名。
- “弱别名查询列”直接指向 `SELECT` 结果列，可以是外部原始列，也可以是查询计算列。
- 一个弱别名列可用英文逗号、中文逗号或换行提供多个简称。

例如，外部库已有 `short_name` 列时：

```sql
SELECT sku AS external_key, product_name, short_name, quantity
FROM stock
WHERE quantity > 0
```

将“弱别名查询列”填为 `short_name`。如果外部库没有简称列，可在只读查询中自行计算一列；Huginn 导入器不会自动猜测品牌或拆解商品名。

## Diaohuo 示例

选择“Diaohuo 电脑库存示例”后，只需填写 `diaohuo.db` 的实际路径和 QQ 监控来源。预设会按完整规格合并有效库存，并示范如何在查询中提供弱别名计算列。路径、查询和字段映射都可修改，核心导入器不依赖 Diaohuo 代码。

## 同步边界与失效提示

- 重复导入按 `(外部数据源, 外部唯一标识)` 幂等；重复发布在写事务内重新读取未发布记录，因此并发点击最多为每条记录创建一个任务。
- 外部查询、字段校验或超限失败时，导入事务不会提交，也不会把既有快照标为失效；外部 SQLite 始终以只读连接打开，Huginn 不执行写入。
- 读取期间如果数据源的查询、字段映射、模板版本或监听来源发生变化，同步会拒绝提交并要求重新检查，避免旧配置覆盖新配置。
- 外部记录消失时只把本地快照标为“失效”，任务继续运行；任务页面显示“关联库存已失效”，用户可使用现有“暂停”操作。记录重新出现时只恢复快照，不自动启用或撤销用户主动暂停。
- 监听来源变化属于已发布任务的配置变化，会生成新的任务修订；仅重复读取相同记录不会生成新修订。

## 当前限制

- 只支持本机 SQLite，只支持手工触发导入。
- 已发布的外部记录发生变化时，确认导入会为对应任务新建修订，保留历史版本。
- 外部记录后续消失时，Huginn 会将本地快照标为失效，但不会自动删除或停用已发布任务。
- 暂不反向写入外部系统，不做自动报价、出库或库存扣减。
