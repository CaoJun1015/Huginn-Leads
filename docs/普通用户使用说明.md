# Huginn Leads 普通用户使用说明

Huginn Leads 会把你指定的 QQ 群和好友消息整理成可以查看、筛选和跟进的业务线索。程序在你的 Windows 电脑本地运行，不需要安装 Python、Node.js，也不会主动发送 QQ 消息。

## 一、使用前需要准备什么

1. 一台 Windows 10 或 Windows 11 的 64 位电脑。
2. 一个用于测试的 QQ 账号。NapCatQQ 属于第三方 QQ 协议端，使用前请了解相关规则和账号风险，建议先用测试账号。
3. 从项目发布页下载的 `Huginn-Leads-版本号-win64.zip`。
4. 从 [NapCatQQ 官方 Releases](https://github.com/NapNeko/NapCatQQ/releases) 下载的 Windows 一键包。

Huginn Leads 项目代码采用 MIT License。NapCatQQ 不包含在 Huginn Leads 中，两者通过 OneBot v11 在本机连接；NapCatQQ 当前许可限制商业用途，本测试包仅用于个人非商业测试。

## 二、解压并启动 Huginn Leads

1. 右键 ZIP，选择“全部解压”。不要直接在压缩包里运行。
2. 打开解压后的文件夹，双击 `start.cmd`。
3. 如果 Windows 弹出安全提示，请先核对文件来源；确认是你从项目发布页下载的文件后再运行。
4. 稍等片刻，浏览器会自动打开 `http://127.0.0.1:18080`。
5. 第一次启动时，黑色窗口会显示一次性初始化码。把它填进网页，然后设置至少 12 位的本地密码。

首次启动会自动生成 `.env`、`data` 和 `backups`。不要把 `.env` 发给别人，因为里面包含连接密钥。

## 三、安装并登录 NapCatQQ

1. 解压并启动 NapCatQQ 官方 Windows 一键包。
2. 按 NapCatQQ 的提示登录 QQ；第一次通常需要扫码。
3. 打开 NapCatQQ 的 WebUI，找到 OneBot 网络配置。
4. 新增一个“反向 WebSocket”配置。

不同版本的 NapCatQQ 页面名称可能略有区别，但需要填写的内容相同。

## 四、连接 NapCatQQ 与 Huginn Leads

在 NapCatQQ 的反向 WebSocket 配置中填写：

```text
地址：ws://127.0.0.1:18080/onebot/v11/ws
Token：Huginn Leads 文件夹中 .env 的 ONEBOT_ACCESS_TOKEN
```

查看 Token 的方法：

1. 回到 Huginn Leads 文件夹。
2. 用记事本打开 `.env`。
3. 找到 `ONEBOT_ACCESS_TOKEN=`。
4. 只复制等号后面的内容到 NapCatQQ，不要增加空格或引号。
5. 保存并启用 NapCatQQ 的反向 WebSocket 配置。

建议先启动 Huginn Leads，再启动 NapCatQQ。连接中断后，NapCatQQ 应自动尝试重连。

## 五、完成首次配置

回到 Huginn Leads 网页：

1. 点击“重新检测”。
2. 确认 Huginn Leads、NoneBot2、NapCatQQ 和 QQ 登录都显示正常。
3. 点击“刷新群和联系人”。
4. 手动开启允许保存消息的群或好友。
5. 点击“完成配置”。

新发现的群和联系人默认关闭。只有你主动开启的来源才会保存新消息。

## 六、基础使用

### 创建关注任务

1. 打开“监控任务”。
2. 新建任务并选择业务模式。
3. 填写想关注的方向、配置、价格、数量或地区。地区仅记录和展示，不参与自动匹配。
4. 如选择有效期，所选本地日期当天仍有效，到次日零点停止。
5. 保存任务。

### 查看和处理线索

1. 新消息命中任务后，会出现在“线索工作台”。
2. 打开线索可以查看原文和每个条件的判断结果。
3. 根据实际处理情况标记为已联系、已完成或已忽略，并填写备注。

### 修改采集范围

进入“数据连接 → 消息渠道”，随时开启或关闭群和好友。关闭后收到的新消息不会保存。

### 检查运行状态

进入“设置 → 系统与数据”，可以查看 QQ 是否在线、是否有处理失败、数据库状态以及备份情况。

## 七、停止、再次启动和升级

- 停止：关闭 Huginn Leads 的黑色窗口；需要完全停止 QQ 接入时，也关闭 NapCatQQ。
- 再次启动：双击 `start.cmd`，原来的设置和数据会继续保留。
- 升级前：先在“设置 → 系统与数据”创建备份并确认最近备份成功，再关闭程序。不要删除旧文件夹，确认新版本可用后再处理。

重要数据位于：

```text
.env                         连接配置
data\huginn-leads.db         数据库
backups\                     备份文件
```

### 恢复备份

先按 Ctrl+C 完全停止 Huginn Leads。在发布包解压目录打开终端，运行：

```text
restore.cmd "backups\huginn-leads-备份时间.db"
```

也可运行 `HuginnLeads.exe restore "D:\备份目录\待恢复.db"`。发布包恢复不需要安装 Python 或 Node.js；运行中的程序会拒绝恢复。恢复前会验证备份并保存当前数据库副本，完成后重新双击 `start.cmd`，登录核对任务、线索和人工备注。

## 八、常见问题

### 浏览器没有自动打开

先看黑色窗口是否报错，然后手动打开 `http://127.0.0.1:18080`。不要关闭黑色窗口。

### NapCatQQ 一直显示未连接

检查反向 WebSocket 地址、Token 是否完全一致，以及 Huginn Leads 是否正在运行。修改后保存配置并重新连接。

### QQ 已登录，但看不到群和好友

先确认 NapCatQQ 已连接，再到首次配置或“数据连接 → 消息渠道”刷新群和联系人。

### 收不到线索

依次确认：来源已经开启、任务正在运行、消息是在连接成功后收到的。断线期间的历史消息不会自动补回。

### 可以把网页开放到公网吗

不可以。当前版本只适合在本机 `127.0.0.1` 使用，不是公网或多人系统。

## 九、隐私提醒

- 不要公开 `.env`、数据库或备份。
- 不要采集未经允许的群和联系人。
- Huginn Leads 不会下载图片和文件，也不会调用云端 AI。
- 数据库和备份默认没有额外加密，请保护好 Windows 登录账户和磁盘。
