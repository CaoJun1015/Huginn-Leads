# 已知限制

- 当前只处理普通群消息和已启用好友联系人的私聊文本；陌生人及临时会话不采集。图片、文件等仅保存受限消息段引用，不下载附件、不做 OCR。
- 自定义字段仅做文字包含匹配，不处理数值区间、日期语义、同义词或否定表达。
- 规则只对显式关键词、供求表达和可证明字段工作；未出现的配置、数量和价格保持未知。
- 多商品只有在可区分的消息行中拆分；同一行存在多个价格时进入待核对。
- WebSocket 重连只证明当前连接恢复，不会自动补回断线期间的历史消息。
- SQLite 数据库和普通备份默认未加密；应使用受控 Windows 账户和磁盘保护。
- 工作台只监听回环地址并具有本地登录保护，但相同 Windows 用户权限下的其他程序仍可能读取本地文件。
- 备份恢复必须停机运行；网页不提供在线上传覆盖数据库。
- 规则质量报告基于模拟样本，真实召回率和误报率需要用户的脱敏标注样本重新测量。
- 当前 NapCat 上游许可限制商业用途，本部署仅适用于用户确认的个人非商业场景。
